# Speak up AI｜TikTok 15秒 台本

## 1. 伸びている投稿の「型」

再生が伸びる短尺動画に多い作りを、4つの役割に分けたもの。特定の投稿の数字を分析したものではない。

| 段階 | 秒数 | 役割 | 作り方のコツ |
| --- | --- | --- | --- |
| 課題 | 0〜3秒 | 指を止めさせる | 「あるある」の瞬間を1枚で見せる。テロップは15文字以内で、相手の心の声にする |
| 共感 | 3〜6秒 | 「わかる」と思わせる | 失敗のあとにやってしまう行動を言い当てる（責めない） |
| 理想 | 6〜9秒 | なりたい姿を見せる | 表情が明るい人物に切り替える。「完璧」ではなく「一歩先」の姿にする |
| 解決策 | 9〜15秒 | 方法と行動を示す | アプリ画面で機能を1つずつ。最後の3秒は行動の呼びかけだけを大きく |

添付素材の役割
- 山で困っている写真 → 課題・共感（翻訳アプリが「通信エラー」で使えない場面）
- カフェで笑顔の写真 → 理想（※写っているスマホのモックは別アプリの画面なので、動画では切り取って使わない）

## 2. 表現について（誇張の修正）

「ネイティブレベルの英語に変わる」は効果の誇張になるので使っていない。アプリで実際にできることだけを言う。

| 言ってよいこと（実装済み） | 言わないこと |
| --- | --- |
| 黙っていると5秒でヒントが出る（10秒で文の型、15秒で例文） | ネイティブレベルになる／ペラペラになる |
| 話した単語の数だけXPがたまり、アバターが育つ | AIが自由に会話してくれる（今は質問が決まった台本） |
| 声で答えられる（対応ブラウザ）・無料で使える | 「◯日で話せる」などの期間の約束 |

## 3. 台本（15秒・1080×1920）

| 秒数 | 画面に映すもの | テロップ | ナレーション |
| --- | --- | --- | --- |
| 0.0–3.0（課題） | 日本の山あいの観光地（遠くに合掌造りの集落、緑の山並み、曇り空）。20代前半の日本人女性（黒髪をひとつ結び、茶色のカーディガン）が眉を寄せ、困った顔で口ごもっている。右手でスマホを胸元に握り、画面には地図アプリと「NETWORK ERROR」の表示。右側から欧米人の女性旅行者（スカーフ、レインコート）が道を尋ねるように顔を寄せている。縦構図、自然光、ドキュメンタリー風写真 | 言いたいのに／**英語が出ない** | 話しかけられた。言いたいことはあるのに、英語が出てこない。 |
| 3.0–6.0（共感） | 同じ場面で女性の顔と、通信エラーのスマホに寄ったバストアップ。こわばった愛想笑い、額に汗。背景はぼかした緑の山 | 笑ってごまかす。／**翻訳アプリ頼み。** | つい笑ってごまかしたり、翻訳アプリに頼ったり。 |
| 6.0–9.0（理想） | 明るいカフェの窓際。同じ女性（茶色のニット）が、スマホを口元近くに持って英語で話しながら、楽しそうに笑っている。手前にラテアートのカップ。スマホの画面は映さない。暖かい自然光、浅い被写界深度 | 詰まっても／**自分の英語で話す** | 詰まっても、自分の言葉で最後まで話せたら。 |
| 9.0–10.5（解決策①） | 紫のグラデーション背景の中央に、スマホ枠に入れた **アプリのスクショ（会話画面・ヒント表示中）**。左に「5秒でヒント」のバッジ | 黙っても**5秒で**／**ヒント**が出る | Speak up AIなら、黙っても5秒でヒントが出る。 |
| 10.5–12.0（解決策②） | 同じ背景で **アプリのスクショ（回答後のフィードバック画面）**。左に「+XP」のバッジ | 話した分だけ／**アバターが育つ** | 話した分だけ、アバターが育つ。 |
| 12.0–15.0（行動） | 同じ背景で **アプリのスクショ（ホーム画面・アバターとLv表示）** を大きく | プロフのリンクから／**無料で試せる** | プロフのリンクから、無料で試せます。 |

※ テロップの「／」は改行位置。太字は黄色で強調する部分。

## 4. 冒頭テロップ 3案

| 案 | テロップ（文字数） | 誰のどんな瞬間に刺さるか |
| --- | --- | --- |
| A（採用） | 言いたいのに英語が出ない（12） | 留学生や観光客に話しかけられて、頭では答えが浮かんでいるのに口から出なかった経験を思い出す人に刺さる。 |
| B | また笑ってごまかした？（11） | 英語で何か聞かれて、愛想笑いとうなずきだけでその場を終わらせてしまい、あとで落ち込んだ人に刺さる。 |
| C | 翻訳アプリ、出すの恥ずかしい（14） | 会話の途中でスマホを取り出して入力する間に、相手を待たせて気まずくなったことがある人に刺さる。 |

## 5. 動画ファイル

- `index.html` … 再生・一時停止・最初から再生ボタンつきのプレイヤー（ブラウザで開く）
- `speak-up-ai-tiktok.mp4` … 投稿用の書き出し（1080×1920・30fps・15秒）。音は無音のトラックだけなので、TikTokで音源やナレーションを足して使う
- テロップは画面の上3分の1（y=230〜650px）に配置し、右端140pxと下側（キャプションの位置）には文字を置いていない
